# Magic app survey, 2026-10-18

Researched by a multi-agent sweep (13 agents, 11 categories, 137 apps) on 2026-10-18. Raw findings with sources per app: `mtg-apps-2026-10-18.json`. The ordered backlog: `backlog-2026-10-18.json`.

# Yama superset: feature taxonomy and backlog

Date: 2026-10-18. Inputs: the research JSON from the eleven category agents (all pages read 2026-10-18), plus Yama's README.md, ARCHITECTURE.md, every page in `web/src` (Cards, Collection, Decks, Group, Table, Play, scanner), `packages/core/src/table.ts`, and the schema in `server/migrations`. I did no new web reads for this step. Reddit could not be read by any of the research agents, so user sentiment comes from app stores, forums, Hacker News and review sites.

## What Yama has today (checked in code)

- **Cards:** Scryfall import with daily dated prices. Search uses a subset of Scryfall syntax (`t: o: c: id<= mv pow f: kw: is:commander`, `-`, `or`, parentheses) and works offline from a 5 MB bundle. The card sheet shows Oracle text, Commander legality, printings with market prices, a price history chart, the artist credit, and +1/+F/+E buttons to add to the collection. Sort by name, mana value, color or "most played" (edhrec_rank). Missing: rulings, the Game Changer flag, role tags.
- **Collection:** binders, boxes, lists and decks. Change condition, proxy flag and container. Adjust quantity. Mythic Tools CSV import and export (idempotent; deck containers become Yama decks). Totals for market value and paid price, both dated. A scanner (OCR prototype) feeds the collection. Missing: bulk edit, splitting a stack, deck usage per row.
- **Decks:** paste any common format. Edit as text; every save makes a version with a note. Commander validation. Owned/needed with the location of each copy and the cheapest market price for the rest (basics excluded, missing prices counted). Sample hands with mulligans and bottoming. Link a deck to its physical container. Archive. The server stores versions; the UI doesn't list or diff them. Missing: stats, brackets, combos, export.
- **Table:** 1-6 players with rotated panels and mana-color bands. Commander damage (partners too), poison, energy, experience, rad, tickets, commander tax, monarch, initiative, day/night, pass turn and turn count, knock out with killer, revive, undo/redo, a loss prompt, wake lock, and a d20 "roll for first" that only shows text (the result isn't recorded). QR shared table where the host is in charge and works offline. `PlayerSetup.art` already holds the commander art crop, but panels don't draw it.
- **Playgroups:** join codes, guests, recent games, logging games played without Yama, win rate by player and by commander, average turns and minutes. Online games count too. The schema already stores `eliminated_by_seat`, `eliminated_turn` and `deck_version_id` per seat, but no stat uses them yet.
- **Online play:** phase v0.113.0. Lobby, join by code, AI seats (Easy, Medium, Hard) with a deck chosen per seat, legal options only, smart stops, full control, hidden information, replay log, resume after restart, final boards, card inspector, game log, concede. The board has a spectator state, but there's no route to it.
- **Platform:** installable PWA, offline shell, offline op queue, Google sign-in with invites, password accounts from the CLI, reduced-motion CSS.
- **Not in Yama at all:** the deck planner, the simulation lab UI, trading and loans, rules reference, the release calendar.

Legend: **Yama** = has / partial / missing. **Value** = to Bryan's Commander group (Android phones, precons with planned upgrades, buys locally, prints the rest at MPC, uses Mythic Tools today, four Star Trek precons arriving about 2026-11-13). **Effort:** S = hours, M = about a day, L = several days.

## 3. Ten ideas worth copying

1. **Results tied to deck versions** (TurnZero HQ). Every game records the version played, and ratings split by version, so you can see what a rebuild did. Yama already stores `game_seats.deck_version_id`.
2. **Approval-first triage** (DeckCheck). Adds and cuts are judged separately: accept, defer to Considering, or reject. Locked cards are never cut, and the last 20 results can be put back or reverted. This maps onto want / maybe / no.
3. **Deck Modules** (DeckFlow). A fixed core, then named modules with their own mana support. Each module compiles to a legality check and an IN/OUT checklist with a way back to baseline. This is the model for bracket swap bags.
4. **Disclosed simulation** (EDHbots). Every result carries a seed, engine revision, card-data date and pinned opponent field. Results come with confidence intervals. A change inside the margin is "no difference" and gets confirmed on a fresh seed. Predictions are registered before real games, and misses are published.
5. **Combos one card away** (Commander Spellbook). Matched against Bryan's collection and spares, this becomes "you already own the missing piece". A warning fires when a swap makes a two-card combo live.
6. **Commander art playmats and group highlights** (Mythic Tools). Art behind each player, which Bryan asked for. Archnemesis, first out, last out and streaks, all computed from data Yama already logs.
7. **Cast to TV and recap links** (Lotus). A watch code that lasts the whole night. Life graphs and knockout lists per game. Underlined 6 and 9 so rotated panels read correctly.
8. **Statistical care** (playgroup.gg). Win rates normalized to a 4-player 25% baseline. Minimum games and pilots. Faded small samples. A "last computed" date on every page.
9. **Deck-to-collection moves** (ManaBox). "Build from collection" finds each copy. Updating a deck shows what to pull and what to put back. Missing-card rules cover exact printings, other decks and proxies.
10. **Set Impact reports** (DeckCheck). When a set is released, each watched deck gets the new cards that fit it, with a reason. Decks with no hits are listed too, so it's clear they were checked. This fits the Star Trek precons in November.

Close runners-up: Moxgate's deck-in-a-URL Challenge Links, Archidekt's price overlay that leaves out owned cards and basics, and Lotus/Treachery.app role dealing to each player's own phone.

## 4. Five complaints Yama should avoid

1. **Scores that drift silently.** DeckCheck replaced its rating system four times in a year and admits run-to-run drift; checkers disagree with each other. Yama should compute brackets with deterministic rules, and stamp each one with its source, date and engine or card-data version.
2. **Prices without dates, or missing prices shown as zero.** AI-written guides show prices with no date, and MTGGoldfish articles show "$0.00" placeholders. Yama should date every price, name its source, and show "no price" rather than $0.
3. **Confusing stats for lent or shared decks.** Mythic Tools logs a game under the pilot's deck, not the lent one. Yama should record the deck owner and the pilot separately.
4. **Buried features and redesigns that drop features.** Monarch is hidden under "Tokens" in Mythic Tools, and Archidekt hides its snapshots. The Deckstats V2 relaunch removed notes, compare and history for a while. Yama should put controls where people use them and never ship a redesign that loses an existing feature.
5. **Brittle outside dependencies.** Moxfield blocks imports. MTG Familiar's prices have been broken since 2026-09-29 because a TCGplayer API call failed. Scryfall's old JPEG sizes disappear on 2027-01-01. Yama should import pasted text, keep its own dated snapshots, and switch image keys early.
